# Quiz Module 4: Cấu Trúc Dữ Liệu

## Câu 1: Kiểu dữ liệu nào KHÔNG thay đổi được?
A. List  B. Dictionary  C. Tuple  D. Set
**Đáp án: C - Tuple**

## Câu 2: Cách tạo set đúng?
A. set = [1, 2, 3]  B. set = {1, 2, 3}  C. set = (1, 2, 3)  D. set = <1, 2, 3>
**Đáp án: B**

## Câu 3: Truy cập giá trị trong dictionary?
A. dict[0]  B. dict.get(key)  C. dict(key)  D. dict->key
**Đáp án: B**

## Câu 4: List comprehension nào tạo số chẵn?
A. [x for x in range(10) if x % 2]
B. [x for x in range(10) if x % 2 == 0]
C. [x if x % 2 for x in range(10)]
D. [x % 2 == 0 for x in range(10)]
**Đáp án: B**

## Câu 5: Toán tử & với set là?
A. Hợp  B. Giao  C. Hiệu  D. Đối xứng
**Đáp án: B - Giao**
