# 🐍 Hệ Thống Học Python Toàn Diện

Chào mừng bạn đến với khóa học Python từ cơ bản đến nâng cao! Khóa học này được thiết kế để giúp bạn **hiểu sâu** và **ghi nhớ bền vững** kiến thức Python.

## 🎯 Mục Tiêu Khóa Học

- Nắm vững các khái niệm cơ bản của Python
- Thực hành qua bài tập thực tế
- Đánh giá kiến thức thông qua các bài kiểm tra
- Xây dựng nền tảng vững chắc cho lập trình Python

## 📚 Cấu Trúc Khóa Học

### Module 1: Biến và Kiểu Dữ Liệu
- Biến, hằng số và quy tắc đặt tên
- Các kiểu dữ liệu cơ bản: int, float, string, boolean
- Ép kiểu và chuyển đổi dữ liệu
- **Thời gian:** 3-5 giờ

### Module 2: Cấu Trúc Điều Khiển
- Câu lệnh điều kiện: if, elif, else
- Vòng lặp: for, while
- Break, continue và pass
- **Thời gian:** 4-6 giờ

### Module 3: Hàm và Module
- Định nghĩa và gọi hàm
- Tham số và giá trị trả về
- Scope và lifetime của biến
- Import và sử dụng module
- **Thời gian:** 5-7 giờ

### Module 4: Cấu Trúc Dữ Liệu
- List, Tuple
- Dictionary, Set
- List comprehension
- Các phương thức xử lý dữ liệu
- **Thời gian:** 6-8 giờ

### Module 5: Lập Trình Hướng Đối Tượng
- Class và Object
- Constructor và Destructor
- Inheritance và Polymorphism
- Encapsulation
- **Thời gian:** 8-10 giờ

### Module 6: Xử Lý File và Exception
- Đọc/ghi file text
- Làm việc với CSV, JSON
- Try-except-finally
- Tạo custom exception
- **Thời gian:** 5-7 giờ

## 📖 Cách Sử Dụng

1. **Học Lý Thuyết:** Đọc file `README.md` trong mỗi module
2. **Thực Hành:** Làm các bài tập trong folder `exercises/`
3. **Kiểm Tra:** Làm bài quiz trong folder `quiz/` để đánh giá
4. **Review:** Xem lại `solution.py` để hiểu cách giải tối ưu

## 💡 Lời Khuyên

- ✅ Thực hành mỗi ngày ít nhất 30 phút
- ✅ Đừng bỏ qua bài tập, hãy tự làm trước khi xem solution
- ✅ Ghi chú những điểm quan trọng
- ✅ Thực hành lại các bài tập sau 1 tuần để củng cố
- ✅ Tạo dự án nhỏ riêng để áp dụng kiến thức
