# Quiz Module 3: Hàm và Module

## Câu 1: Keyword để định nghĩa hàm?
A. function  B. def  C. func  D. define
**Đáp án: B**

## Câu 2: Hàm trả về giá trị bằng?
A. give  B. return  C. send  D. output
**Đáp án: B**

## Câu 3: Lambda function là gì?
A. Hàm lớn  B. Hàm đệ quy  C. Hàm ẩn danh  D. Hàm module
**Đáp án: C**

## Câu 4: *args dùng để?
A. Nhận số lượng tham số không xác định
B. Nhận dictionary
C. Nhận list
D. Nhận tuple
**Đáp án: A**

## Câu 5: Import math as m có nghĩa?
A. Import module math với tên ngắn m
B. Lỗi cú pháp
C. Import một phần math
D. Xóa module math
**Đáp án: A**
