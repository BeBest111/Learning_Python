# Quiz Module 6: File và Exception

## Câu 1: Mode nào để ghi đè file?
A. "r"  B. "w"  C. "a"  D. "x"
**Đáp án: B - "w" ghi đè, "a" thêm vào cuối**

## Câu 2: with open() có lợi ích gì?
A. Nhanh hơn
B. Tự động đóng file
C. Đọc nhiều file
D. Ghi file nhanh
**Đáp án: B**

## Câu 3: json.dump() làm gì?
A. Đọc JSON
B. Ghi dictionary vào JSON file
C. Parse JSON string
D. Validate JSON
**Đáp án: B**

## Câu 4: Try-except dùng để?
A. Tăng tốc code
B. Bắt và xử lý lỗi
C. Debug code
D. Test code
**Đáp án: B**

## Câu 5: Khối nào LUÔN chạy?
A. try  B. except  C. else  D. finally
**Đáp án: D - finally luôn chạy**
