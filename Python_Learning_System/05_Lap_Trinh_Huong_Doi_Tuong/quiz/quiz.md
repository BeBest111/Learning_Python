# Quiz Module 5: OOP

## Câu 1: Constructor trong Python là?
A. __init__  B. __new__  C. __construct__  D. constructor()
**Đáp án: A**

## Câu 2: self đại diện cho?
A. Lớp  B. Đối tượng hiện tại  C. Phương thức  D. Thuộc tính
**Đáp án: B**

## Câu 3: Cách tạo thuộc tính private?
A. _var  B. __var  C. private var  D. #var
**Đáp án: B**

## Câu 4: Kế thừa trong Python?
A. class Child(Parent)  
B. class Child extends Parent
C. class Child : Parent
D. class Child -> Parent
**Đáp án: A**

## Câu 5: @staticmethod dùng để?
A. Tạo method không cần object
B. Tạo method private
C. Tạo method protected
D. Tạo constructor
**Đáp án: A**
